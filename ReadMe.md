### MAUI C# Fiddle 🚀

MAUI C# Fiddle is a lightweight and versatile code runner for **Windows** and **Android**, designed for developers, students, and hobbyists who need to quickly test C# code snippets.

**

Built with .NET MAUI and powered by the **Roslyn Scripting API**, this application provides an interactive environment to write and execute C# code on the fly. You can see immediate results, manage code files with open and save functionality, and experiment with C# logic without the need to create a full project. It's the perfect pocket tool for prototyping, learning, and verifying code on the go.
